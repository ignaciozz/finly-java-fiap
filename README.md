# Finly Java

Projeto acadêmico de um sistema **Fintech desenvolvido em Java**.

## Sobre o projeto

Este projeto foi desenvolvido como parte das atividades acadêmicas de programação e tem como objetivo construir, de forma gradual, um sistema Fintech utilizando conceitos de **Programação Orientada a Objetos (POO)**.

Nesta primeira etapa foram definidas as principais classes do sistema, seus atributos e métodos.

## Classes

* `Usuario` — representa o usuário da plataforma.
* `Conta` — representa a conta financeira do usuário.
* `Transacao` — representa as transações realizadas.
* `Cartao` — representa o cartão do usuário.
* `Main` — utilizada para testar a execução dos métodos.
